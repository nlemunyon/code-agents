# Supply-chain audit

- Inspect tracked configuration for credentials without printing values or
  broadening into unrequested history.
- Review pinning, lockfiles, provenance, integrity, lifecycle scripts, generated
  artifacts, registries, and updates.
- Evaluate dependency issues against resolved versions, reachable features,
  runtime, and compensating controls.
- Review CI/CD token scope, untrusted contributions, artifact trust, release
  permissions represented in repository evidence, SBOMs, signing, and scanning.
