# Runtime and cloud audit

- Review images, build context, runtime user, capabilities, mounts, exposure,
  health, limits, and secret injection.
- Review infrastructure identity, privilege, network paths, encryption, public
  exposure, logs, backup, recovery, and drift.
- Verify cloud and GovCloud Region, partition, service, endpoint, and FIPS claims.
- Check alerting, incident response, dependency failure, abuse controls,
  recovery, rollback, and cross-partition flows.
