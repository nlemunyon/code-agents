# Data and cryptography audit

- Trace sensitive data collection, minimization, validation, storage, access,
  encryption, backup, export, retention, deletion, logging, and recovery.
- Review database roles, tenant isolation, queries, migration privileges,
  transactions, workflow lineage, and restore authority.
- Review supported primitives and key management; investigate custom crypto,
  hard-coded keys, nonce reuse, weak randomness, and missing rotation.
