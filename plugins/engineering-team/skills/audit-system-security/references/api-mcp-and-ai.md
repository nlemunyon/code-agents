# API, MCP, and AI/ML audit

- Verify authentication, authorization, tenancy, consequential-action
  confirmation, schemas, capabilities, returned data, cancellation, and bounds.
- Treat tool output, retrieved content, model output, prompts, and uploads as
  untrusted across agent and MCP boundaries.
- Trace plausible prompt injection, tool confusion, excessive agency,
  exfiltration, poisoning, unsafe model loading, leakage, cross-user memory, and
  unbounded inference cost.
- Verify provider retention, transmission, logging, and residency assumptions.
