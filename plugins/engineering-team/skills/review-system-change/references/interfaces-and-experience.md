# Interface and experience review

- Trace server schemas through clients, MCP adapters, protocols, and generated
  artifacts; verify names, defaults, errors, retries, and timeouts.
- Confirm authentication, authorization, tenancy, cancellation, and
  consequential-action confirmation at each boundary.
- Exercise supported end-to-end paths, not only mocked internals.
- Where UI/UX changed, review flows, interaction states, content, responsive
  behavior, keyboard access, semantics, focus, and error recovery.
