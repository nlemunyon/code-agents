# Runtime and delivery review

- Images build reproducibly, use trusted inputs, and run as the intended user.
- Secrets, health, startup, shutdown, signals, limits, dependency failure,
  retries, and rollback are handled.
- Infrastructure identity, network exposure, encryption, backup, restore, and
  drift are least privilege and reversible.
- Review CI/CD permissions, untrusted contributions, provenance, signing,
  scanners, generated artifacts, and promotion controls.
- Logs, metrics, traces, alerts, dashboards, and runbooks cover the changed path.
