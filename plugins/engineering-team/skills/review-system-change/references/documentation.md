# Documentation review

- Inventory every affected public surface with source, owner, and verification.
- Ensure README, developer, API, client, MCP, schema, error, compatibility,
  operational, migration, rollback, and release guidance matches behavior.
- Verify safe examples and expected results; explain caller errors and recovery
  or state an explicit `Not applicable` reason.
- Enforce U.S. grade 12 or lower prose, portable paths, current links, and the
  fail-closed documentation-quality gate.
